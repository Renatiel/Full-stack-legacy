Guia Rápido de Git

Introdução

Git é um sistema de controle de versão distribuído. Cada cópia do repositório carrega o histórico completo do projeto, então você pode trabalhar offline e sincronizar quando quiser.

Este guia reúne os comandos que mais aparecem no dia a dia, sem tentar cobrir cada opção existente — apenas o essencial para manter um fluxo de trabalho tranquilo.

  • Funciona de forma local, sem depender de um servidor central
  • Guarda snapshots do projeto, não apenas diferenças entre arquivos
  • É a base de plataformas como GitHub, GitLab e Bitbucket
Configuração Inicial

Antes do primeiro commit, informe seu nome e e-mail. Essas informações ficam registradas em cada alteração que você enviar.

git config --global user.name "Seu Nome"
git config --global user.email "voce@exemplo.com"

Para transformar uma pasta comum em um repositório Git, use git init. Para copiar um repositório já existente, use git clone.

git init
git clone https://github.com/usuario/projeto.git
Comandos Básicos

O ciclo mais comum envolve verificar o estado dos arquivos, adicioná-los à área de preparação e registrar as mudanças em um commit.

git status
git add arquivo.txt
git commit -m "Mensagem descrevendo a mudança"

Alguns comandos úteis para o dia a dia:

  • git status mostra o que mudou desde o último commit
  • git add . prepara todos os arquivos modificados
  • git log lista o histórico de commits
  • git diff mostra as diferenças linha a linha
Branches e Merge

Branches permitem desenvolver uma funcionalidade sem afetar o código principal. Quando o trabalho estiver pronto, ele pode ser incorporado de volta.

git branch nova-funcionalidade
git checkout nova-funcionalidade
git checkout -b outra-forma-de-criar-e-trocar

Para juntar o trabalho de um branch em outro, use git merge a partir do branch de destino.

git checkout main
git merge nova-funcionalidade
  • Prefira nomes de branch curtos e descritivos
  • Resolva conflitos com calma, editando os arquivos marcados
Trabalhando com Remotos

Um repositório remoto é uma cópia do projeto hospedada em outro lugar, geralmente usada para colaborar com outras pessoas.

git remote add origin https://github.com/usuario/projeto.git
git push -u origin main
git pull origin main
  • git push envia seus commits locais para o remoto
  • git pull traz e mescla as mudanças do remoto
  • git fetch baixa as mudanças sem mesclar automaticamente
Desfazendo Alterações

Nem todo commit é definitivo. Git oferece algumas formas de voltar atrás, dependendo de quão longe você já foi.

git restore arquivo.txt
git reset --soft HEAD~1
git revert <hash-do-commit>

git restore descarta mudanças não commitadas, git reset reescreve o histórico local e git revert cria um novo commit desfazendo outro, com segurança para históricos já compartilhados.
