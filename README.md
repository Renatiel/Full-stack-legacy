# 🎓 Certificação Full Stack (Legacy) — freeCodeCamp

Este repositório contém a resolução de todos os projetos e exercícios práticos da trilha **Full Stack Developer (Legacy)** do [freeCodeCamp](https://www.freecodecamp.org/). 

A formação abrange desde os fundamentos de desenvolvimento web front-end com HTML5 e CSS3 até o desenvolvimento back-end assíncrono com Node.js, Express e bancos de dados MongoDB, incluindo testes automatizados e segurança da informação.

---

## 📑 Conteúdo do Curso e Módulos

O currículo Full Stack Legacy é composto por **10 certificações principais** (mais de 3.000 horas de código prático):

1. **Responsive Web Design**
2. **JavaScript Algorithms and Data Structures**
3. **Front End Development Libraries**
4. **Data Visualization**
5. **Relational Database**
6. **Back End Development and APIs**
7. **Quality Assurance**
8. **Information Security**
9. **Scientific Computing with Python**
10. **Data Analysis with Python**

---

## 🛠️ Tecnologias Utilizadas

### **Front-End**
- **Linguagens & Estilização:** HTML5, CSS3, JavaScript (ES6+), Sass/SCSS
- **Frameworks & Bibliotecas:** React.js, Redux, jQuery, Bootstrap
- **Visualização de Dados:** D3.js

### **Back-End & Bancos de Dados**
- **Ambiente de Execução:** Node.js
- **Framework Web:** Express.js
- **Bancos de Dados:** MongoDB (com Mongoose ORM), PostgreSQL (com Bash e Git)
- **Segurança & Testes:** Helmet.js, Chai, Mocha, Chai-HTTP
